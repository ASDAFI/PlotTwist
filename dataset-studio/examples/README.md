# Example workspace

These three small records demonstrate the editor. All reuse the same visual riddle; two additional questions and all model responses are illustrative, not benchmark measurements. Replace these paths in `.env` with your own data.

The example image is the riddle linked in the supplied dataset example, from Jagran Josh (the article credits Brightside). No reuse license was supplied; it is a demonstration asset, not an assertion that this image is openly licensed. See `docs/ASSETS.md` for attribution.

Each response identifies its question with `image.path`. Use that default mapping when importing the five example JSONL files.
